This phone

Stored only in this browser. The token is sent only to api.github.com to start runs and read their status. The passphrase never leaves the phone.

How to get a token

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate.
  2. Repository access: Only select repositories → this repo.
  3. Permissions: Actions: Read and write. Leave the rest at defaults.
  4. Copy it into the field above and Save.

Coverage & contacts (optional keys, set once on the PC)

India results: gh secret set APIFY_TOKEN — the search then rents real Naukri / Indeed / LinkedIn scrapers on Apify (a few cents per search). Repo variable APIFY_SOURCES picks them (default naukri,indeed; add linkedin to get the job poster as a contact).

Recruiter / hiring-manager contacts on every report: any of SIGNALHIRE_API_KEY, HUNTER_API_KEY, APOLLO_API_KEY as repo secrets. Without keys you still get the emails the postings mention plus ready-made LinkedIn people searches.

Company-site applications: by default the PC opens the career page and fills and submits the form from your details, skipping sites that need a login / account or show a CAPTCHA (those are marked "by hand"). To have Simplify Copilot fill the forms first, sign in once on the PC with python -m naukri.jobs.simplify --setup and set simplify: true in jobs.yaml (or pick the Simplify option under Queue → Rules). Simplify Copilot must be installed in Chrome.
