# Companies whose career pages the careers bot reads (phone page -> Careers tab, or careers_bot.py).
#
# One company per line:   Name | ats | board | note
#
#   ats     greenhouse | lever | ashby | smartrecruiters | recruitee | workday
#   board   the company's id on that job board:
#             greenhouse       boards.greenhouse.io/<board>          e.g. agoda
#             lever            jobs.lever.co/<board>                 e.g. spotify
#             ashby            jobs.ashbyhq.com/<board>              e.g. supercell
#             smartrecruiters  jobs.smartrecruiters.com/<board>      e.g. grab
#             recruitee        <board>.recruitee.com                 e.g. bunq
#             workday          <host>/<tenant>/<site> from the careers URL
#                              e.g. nvidia.wd5.myworkdayjobs.com/nvidia/NVIDIAExternalCareerSite
#   note    free text shown on the phone (hubs, anything you want to remember)
#
# Not sure which board a company uses?  python job-hunt/scripts/careers_bot.py find "<company>"
# Check the whole list still works:      python job-hunt/scripts/careers_bot.py check
#
# Not supported yet (own career sites, no public job-board API): Booking.com, Zalando, Revolut, Atlassian, Shopify.
